#Дашборд продаж автодилера



## Описание
Интерактивный дашборд для отслеживания продаж автодилера с возможностью:
- Загрузки данных из JSON
- Автоматической агрегации по месяцам
- Прогнозирования выполнения планов
- Визуализации через графики и радар-диаграммы
- Системы авторизации с ролями (админ/наблюдатель)

## Технологии1
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Backend: Node.js, Express
- База данных: PostgreSQL (Neon)
- Графики: Chart.js
- Деплой: Vercel

## Надёжность локального fallback

После успешного ответа источника API сначала записывает JSON в уникальный временный
файл, затем заменяет fallback атомарным `rename`. Перед заменой процессы получают
общую файловую блокировку `<fallback>.lock` через эксклюзивное создание файла, поэтому
несколько экземпляров, использующих одну и ту же файловую систему, не записывают
fallback одновременно. Если блокировка занята дольше `FALLBACK_LOCK_TIMEOUT_MS`
(по умолчанию 5 секунд), внешний ответ всё равно возвращается, а предыдущая копия
сохраняется.

В конфигурации Vercel `api/index.js` работает в serverless-экземплярах с локальной
эфемерной файловой системой. Файловая блокировка координирует процессы только внутри
одного экземпляра или общего тома; разные Vercel-экземпляры не делят этот fallback.
Для общего долговечного fallback между экземплярами потребуется внешнее общее
хранилище, а локальная копия должна рассматриваться как best-effort кэш.
